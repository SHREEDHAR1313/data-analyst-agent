# AI Data Analyst Agent

A Streamlit data-analysis agent that lets you upload a CSV and ask questions in plain English. Gemini chooses from a small set of deterministic Python tools; pandas/numpy/matplotlib perform the actual analysis.

## What was fixed

- Replaced the unavailable `gemini-2.5-flash` model with `gemini-3.6-flash`.
- Migrated the Gemini agent to Google's **Interactions API**, the current recommended interface for new Gemini agent projects.
- Updated Gemini function-calling declarations to the Interactions API format.
- Added safer tool error handling so a bad column/tool argument is returned to Gemini instead of crashing the app.
- Fixed chart paths so they work regardless of the directory from which Streamlit is launched.
- Sanitized chart filenames for unusual column names.
- Fixed `count` group aggregation so it does not require the value column to be numeric.
- Fixed Streamlit session handling so chat history is not reset on every rerun for the same dataset.
- Prevented charts from previous questions from being attached to a new answer.
- Added clearer CSV/API-key error messages.
- Removed generated `__pycache__` files from the distributable project.

## Setup on Windows

Open the project folder in VS Code Terminal:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and put your Google AI Studio key in it:

```env
GOOGLE_API_KEY=your-real-key-here
GEMINI_MODEL=gemini-3.6-flash
```

Then start the app:

```powershell
streamlit run app.py
```

If PowerShell blocks activation, you can skip activation and run:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## First test

The included sample dataset is in `sample_data/sales_data.csv`. Start the app and try:

- `Give me an overview of this dataset and flag any data quality issues.`
- `What's driving revenue the most?`
- `Are there any outliers in revenue?`
- `Show me revenue by region as a chart.`
- `Is there a relationship between unit price and units sold?`

```text
data-analyst-agent/
├── app.py                  # Streamlit UI
├── agent_gemini.py         # Gemini Interactions API + tool orchestration
├── tools.py                # Deterministic pandas/numpy/matplotlib tools
├── requirements.txt
├── .env.example
├── sample_data/
│   └── sales_data.csv
└── outputs/                # Generated charts appear here
```

## Security note

Never commit `.env` or share your API key. The `.gitignore` file already excludes `.env`.

The agent does not execute arbitrary Python generated by Gemini. Gemini can only call the registered analysis functions in `tools.py`.
